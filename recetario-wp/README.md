# Tema WordPress Recetario

1. Instalá WordPress normalmente en tu hosting o entorno local.
2. Copiá la carpeta `recetario-wp` a `wp-content/themes/`.
3. En **Apariencia → Temas**, activá **Recetario**.
4. En **Recetas → Agregar receta**, cargá título, descripción, imagen destacada, categoría y dificultad.

Al activarlo se crean las categorías Carne, Pasta y Pescado, y las dificultades Básica e Intermedia. La página principal muestra las últimas seis recetas y `/recetas/` permite filtrarlas.
